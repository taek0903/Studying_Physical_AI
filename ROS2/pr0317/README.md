## 트러블슈팅: VS Code에서 커스텀 메시지 Import 에러 (빨간 밑줄) 현상

### 문제 상황
GUI(탐색기 등)를 통해 `ex_calculator` 패키지 폴더를 직접 VS Code로 열면, 파이썬 코드 상단의 `from ros_study_msgs.msg import ...` 부분에 모듈을 찾을 수 없다는 에러(빨간 밑줄)가 발생함.

### 원인 분석
이 문제는 `ros_study_msgs`가 파이썬 내장 라이브러리가 아닌, **별도로 빌드된 외부 인터페이스(커스텀 패키지)**이기 때문에 발생합니다.

1. `ros_study_msgs` 패키지를 빌드하면 그 결과물은 현재 작업 폴더가 아닌, 워크스페이스의 `~/ros2_ws/install/` 경로에 생성됩니다.
2. 일반적인 방법으로 VS Code를 실행하면, 파이썬 검사기(Linter)는 OS의 '기본 파이썬 경로'만 탐색하므로 `install` 폴더 안에 숨겨진 외부 인터페이스를 찾지 못합니다.

### 💡 해결 방법
단순히 워크스페이스 공간(`~/ros2_ws`)에서 여는 것뿐만 아니라, **터미널에 환경 변수를 적용(sourcing)한 후 해당 터미널에서 VS Code를 실행**해야 합니다.

1. 터미널을 열고 워크스페이스 최상단으로 이동합니다.
   ```bash
   cd ~/ros2_ws

2. 새로 빌드된 외부 인터페이스 경로를 시스템(파이썬 경로)에 인식시킵니다.
source install/setup.bash

3. 환경 변수가 적용된 해당 터미널에서 바로 VS Code를 실행합니다
code .

결과: VS Code가 터미널의 환경 변수(파이썬 외부 패키지 경로)를 그대로 물려받아 실행되므로, ros_study_msgs 임포트 에러가 사라지고 정상적으로 인식됩니다.
