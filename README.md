# Studying Physical AI

컴퓨터 비전, 딥러닝, ROS2를 학습하며 배운 내용을
직접 손코딩으로 재현하고 기록한 저장소입니다.

## 학습 흐름

| 폴더 | 내용 |
|------|------|
| `Python` | Python 문법 및 기초 실습 |
| `AI_기본` | numpy/pandas 데이터 처리, 선형회귀·분류 등 머신러닝 기초 구현 |
| `AI_응용` | 컴퓨터 비전 및 딥러닝 모델 구현 (상세 내용은 폴더 README 참고) |
| `ROS2` | ROS2 패키지 구조 및 인터페이스 설계 학습 (진행 중) |

## 학습 방식

- 이론 학습 후 직접 손코딩으로 재현
- 단순 복붙 없이 구조와 로직을 이해하며 구현
- 환경 이식 및 오류 해결 과정도 함께 기록

## 주요 경험

- Colab → Windows 이식 과정에서 멀티프로세싱 오류를
  직접 원인 분석하고 해결
- Linux 환경에서 ROS2 패키지 구조 학습 중
