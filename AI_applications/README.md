## 핵심 개념 정리

### 통합그래디언트 (Integrated Gradients)
기준선(0)에서 실제 입력 이미지까지의 경로를 따라
모델 예측 변화에 대한 기울기를 누적(적분)하여
각 픽셀이 예측에 얼마나 기여했는지 수치화하는 기법

- 기준선: 아무 정보도 없는 상태 (픽셀값 0)
- 경로 이동: 예측값 변화에 대한 기울기 계산
- 영향력 누적: 리만 합으로 각 픽셀의 기여도 수치화

## 트러블슈팅

### 1. CPU/GPU 디바이스 불일치 오류

**증상**
sample_data는 CPU에 있고 모델은 GPU에 올라가 있어
연산 불가 오류 발생

**원인**
device 설정 누락으로 입력 데이터와 모델이
서로 다른 디바이스에 위치

**해결**
sample_data에 .to(device) 적용하여 GPU로 이동

---

### 2. ValueError: You have to specify pixel_values

**환경:** Google Colab → Windows 이식 과정

**증상**
Windows 환경에서 멀티프로세싱 실행 시 pixel_values 누락 에러 반복 발생

**원인**
Windows는 멀티프로세싱 시 자식 프로세스가 전체 코드를 다시 읽어 내려온다.
이때 if __name__ == '__main__' 블록을 건너뛰기 때문에
전처리 과정이 실행되지 않아 pixel_values가 생성되지 않는다.
전처리가 누락된 빈 데이터로 훈련을 시도하면서 에러가 반복된다.

**해결**
모든 실행 코드를 if __name__ == '__main__' 블록 안으로 이동
